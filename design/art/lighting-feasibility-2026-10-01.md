# Оценка осуществимости: 2D-персонажи + 3D-окружение + свет на web

> **Автор**: technical-artist · **Дата**: 2026-10-01 · **Статус**: вход для art bible §2–8 и поправок ADR-0002/0007
> **⚠ 2026-10-01 — бюджеты §3 и §5 пересмотрены владельцем** («качество важнее мегабайт»): `.pck` ≤ 8,0 МБ, texture memory ≤ 96 МБ, спрайты персонажей 192×256 @ 128 px/м без мипов, 4 архетипа гостя — см. `art-bible.md` A7, §8 и ADR-0007 Amendment 2026-10-01. Числа ниже (48 МБ, 3 МБ, кадр 192–256 с урезанием атласов) — исходная оценка, не действующий стандарт. Техника (§1–2, §4) остаётся в силе.
> Godot 4.7.2, Compatibility, WebGL2. Основано на знании Godot ≤ 4.6 + `docs/engine-reference/godot/`; пункты «needs verification» — проверить на 4.7 и на устройстве.

## 1. Что доступно в Compatibility (web)

| Возможность | Статус |
|---|---|
| DirectionalLight3D + shadow map | Да, 1 направленный свет. Omni/Spot-тени на web не рекомендуются |
| Мягкие тени | Только фильтр (shadow filter quality), PCSS нет. Цена в 4.7 — needs verification |
| SSAO, SSIL, SSR, SDFGI, VoxelGI | Нет (только Forward+/Mobile) |
| LightmapGI | Запекание в редакторе; рендер лайтмапы + baked AO в Compatibility — да. Probes для динамики — needs verification, полагаться только на статику |
| Glow | Есть с 4.3+, дорого на слабых GPU; на low-tier выключен. Поведение в 4.6+ на WebGL2 — needs verification |
| Tonemap / adjustments | Да, дёшево |
| Fog | Depth fog — да, дёшево. Volumetric — нет. Height fog — needs verification |
| DOF | Нет. Только фейк |
| Compositor / CompositorEffect | Нет (нужен RenderingDevice) |
| Свой post-process (screen_texture) | Работает, но копия буфера — дорого на мобилке; не использовать |
| Shader baker (4.5) | Не работает на GL/WebGL (уже в ADR-0007) |
| MSAA | На web не полагаться |

## 2. Рекомендуемый стек (~80 % вида)

1. **Статика окружения** — свет и AO запечены в vertex colors, unshaded-материал (~0 мс, 0 КБ). LightmapGI — только для 1–2 крупных поверхностей (пол, стены), один атлас 512–1024.
2. **Один DirectionalLight3D** с тенями только для динамики (персонажи, гости, чашки); shadow map 1024, 1 каскад, узкая дистанция; статика не в теневом проходе.
3. **Тени спрайтов** — невидимый shadow-only меш-заместитель (капсула, `SHADOWS_ONLY`) + blob-контакт под ногами. Тень от плоской карточки выглядит странно.
4. **Материал спрайтов** — свой spatial-шейдер: unshaded-база + множитель зоны освещения по world-position + ступенчатый ramp 2–3 шага от единственного света (по условной нормали) + rim-tint; приём теней от 3D через `SHADOW_ATTENUATION` — needs verification. Стандартный lit Sprite3D не брать — «картон с градиентом».
5. **Атмосфера** — depth fog + полупрозрачные gradient-quad'ы (блики, виньетка, «лучи»).
6. **Фейк DOF** — дальний фон заранее размытым слоем; runtime blur нет.
7. **Tonemap** (Filmic/ACES-like) + цветокоррекция.
8. **Слияние статики** в 1–3 меша по материалу (ADR-0007 contingency 2).

## 3. Стоимость (оценки, не замеры)

| Техника | GPU / кадр | Размер |
|---|---|---|
| Vertex-color AO/свет | ~0 | 0 |
| LightmapGI 1024 | ~0 | +0,3–1 МБ |
| Shadow map 1024, 1 каскад | 1–3 мс на слабом Adreno/Mali; +1 draw call на caster | ~4 МБ VRAM |
| Мягкий фильтр теней | +0,5–1,5 мс | — |
| Toon-шейдер спрайтов | +0,2–0,5 мс | — |
| Depth fog | ~0,1 мс | — |
| Tonemap | 0,1–0,3 мс | — |
| Glow | 1,5–4 мс | — |

**Уровни качества:** Low — без реальных теней (blob + запечённое), без glow и мягкого фильтра; Mid — тени 512, простой фильтр; High (десктоп/флагман) — тени 1024–2048, мягкие, лёгкий glow. Выбор — статический детект + ручной переключатель в настройках (runtime-адаптация отложена ADR-0007).

**Бюджеты ADR-0007:** census ≤ 75 инстансов / ≤ 150 draw calls не учитывает теневой проход и 3D-меши — добавить «shadow casters ≤ 12, считаются в draw calls». `.pck` 3,0 МБ под арт, вероятно, мал для 3D-моделей + лайтмап + спрайтов высокого разрешения — возможен пересмотр до ~4 МБ (решает владелец).

## 4. Поправки ADR и риски

- **ADR-0002**: §4 (всё unshaded, без света), §7 (без tonemap/glow/lights), Implementation Guidelines («never add DirectionalLight3D»), Alternative 5 (станет принятой в урезанном виде); Kitchen GDD TR-layout-016; Visual Identity Anchor в концепте.
- **ADR-0007**: §3 «No real-time lights, shadows, post-processing», census/draw calls, texture memory 48 МБ, §4 размер `.pck`, §7 pre-warm (варианты шейдеров с тенями).
- **Возможно новый ADR**: Quality Tiers.

**Spike на устройстве до фиксации:**
1. Shadow map + shadow-only капсулы + toon-шейдер спрайтов на слабом Android (Adreno 5xx / Mali-G5x, Chrome): мс кадра и draw calls с тенями и без, `render_scale` 0,6–1,0; прозрачные спрайты как casters/receivers.
2. LightmapGI + vertex-color AO на WebGL2: размер, артефакты; порядок рисования опаковых мешей и blended-спрайтов (гость за стойкой; depth prepass на мобилках выключен — ADR-0002 Risks).
3. Менее критично: ортокамера + направленный свет — bias / peter-panning на малом масштабе.

## 5. Последствия для стандартов арта (предложения)

- **3D-окружение**: вся кухня ≤ 15–20 k треугольников; объект ≤ 1,5 k, станция 500–1000; статика в ≤ 3 меша; без скиннинга; flat/vertex-color.
- **Текстуры окружения**: атлас ≤ 1024²; лайтмап 512–1024 отдельно; vertex colors вместо текстур, где можно; общий texture memory ≤ 48 МБ с учётом мипов ×1,33.
- **Спрайты персонажей**: на экране ~64–100 dp (210–330 физ. px) → кадр-источник 192–256 px по высоте, 4 направления (бок зеркалится), 4–6 кадров на цикл. Атлас ≤ 2048 (лимит WebGL2), но 2048² RGBA8 ≈ 22 МБ с мипами → атласы 1024×2048 / 1024² на роль или кадр 192 px.
- **Формат**: исходники PNG/WebP lossless; без VRAM compression (иначе на web нужны оба набора S3TC/BPTC + ETC2/ASTC — удвоение `.pck`; рисованные градиенты дают артефакты). Мипмапы vs резкость контура — решается spike.
- **AI-генерация + дочистка**: единая линия и палитра, чистая альфа без ореола, единый масштаб (px/м), пивот у ног во всех кадрах, **без запечённых теней в рисунке** (тень даёт движок), нейтральный плоский свет в рисунке.
- **Нейминг**: `assets/art/<категория>/<имя>_<вариант>.ext`, snake_case, префиксы `chr_ / env_ / prop_ / fx_ / ui_ / lm_`; 3D — GLB, метры, Y-up, пивот в основании, канал vertex color обязателен для AO.
- **Проверки**: скрипт валидации импорта (размер ≤ 2048, число треугольников, нет VRAM compression, alpha bleed).
