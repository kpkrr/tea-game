# PROTOTYPE — kitchen-core

**Статус:** in-progress

> Одноразовый код. Не переносить в `src/`: когда вопрос отвечен, решения
> переходят в GDD, а прототип удаляется.

## Вопрос

Весело ли ядро Tea Rush: бариста в 3D-кухне (2.5D, фиксированная камера),
управление тапом по станции, заказы на 3 / 4 / 5 шагов, растущая сложность,
конец партии после 3 ушедших гостей?

## Критерии успеха

- [ ] После партии хочется сыграть ещё раз.
- [ ] К ~2-й минуте тяжело, но проигрыш ощущается своей ошибкой.
- [ ] Есть реальный выбор между дорогим заказом и двумя дешёвыми.
- [ ] Открывается в Telegram на телефоне, грузится быстро, держит ~60 FPS
      (отдельный шаг: web-экспорт + Mini App).

## Запуск

```
/Applications/Godot.app/Contents/MacOS/Godot --path . res://prototypes/kitchen-core/kitchen_core.tscn
```

Мышь на компьютере работает как тап.

## Решения, заложенные в прототип (2026-09-26)

| Тема | Решение |
|---|---|
| Управление | Тап по станции или гостю — идёт и делает действие; тап по полу — просто идёт в эту точку. Без очереди: новый тап сразу перенаправляет баристу |
| Невозможное действие | Бариста не идёт, станция мигает красным |
| Руки | Одна чашка за раз |
| Ошибка в рецепте | Чашку в мусорку, начать заново |
| Шаги | Мгновенные, кроме заварки: она идёт таймером в фоне |
| Готовая заварка | Ждёт сколько угодно, но занимает чайник, пока её не забрали |
| Замена | Слот: чашка в руках ↔ чашка в слоте одним тапом. Чайник: с чашкой «чашка + лист» в руках забираешь готовый чай и сразу ставишь новый; если ещё заваривается — бариста ждёт у чайника и меняет, как только готово |
| Подача | Любому гостю с таким же заказом |
| Кухня | Вертикальный прямоугольник ~8×11 м: станции по стенам с промежутками, в центре широкий остров 2×4 (каждый ряд со своей стороны, бариста обходит его: путь по сетке держится середины проходов, затем спрямляется, где видна прямая) |
| Пустые слоты | Поставить, забрать или обменять чашку; на чашку в слоте ничего не добавляется. 8 слотов: 6 на острове, по 1 у левой и правой стены |
| Стены | Промежутки между станциями у стен закрыты глухими блоками (не используются; что там будет — решим позже) |
| Сложность | Линейный рост с первой секунды до 3:00 (плейтест: плоская первая минута скучна, а потом «бум»). Поток гостей линейный в гостях/мин: 8 → 18; терпение 50 → 25 с; доля «Особых» 0 → 40% |
| Цвета шагов | Чашка — белый, термос — фиолетовый, лист — зелёный, кипяток — красный, вода 80° — синий, добавка — жёлтый. Станция окрашена в цвет своего шага; рецепт каждого заказа, чашка в руках и чашка в слоте показаны рядом цветных квадратов (позже — иконки) |
| Монеты | Цена напитка; идут в кассу |
| Касса | Базово 250 монет: плейтест 2026-09-27 — партия 222 с, ~84 монеты при средней вовлечённости; 250 ≈ 3 партии ≈ 10–11 мин в день. Копится между партиями в рамках запуска, без сохранения. Полна → монеты больше не идут, очки идут; после партии «Чайная закрыта до завтра». Кнопка «Новый день (тест)» обнуляет кассу |
| Бусты (имитация доната) | Панель внизу, крутится прямо в партии. Касса: ур. 0–3 = 250 / 350 / 500 / 700. Скорость баристы: ур. 0–3 = ×1.0 / 1.15 / 1.3 / 1.5 (ходьба и заварка). Поднять кассу при закрытой чайной — снова можно играть |
| Очки | Цена × 10 × (1 + доля оставшегося терпения гостя) |

Напитки (посуда и подача есть всегда):

| Напиток | Шаги | Цена (старт) |
|---|---|---|
| Из термоса | чашка → термос → подача | 2 |
| Заварной | чашка → лист → кипяток 100° (заварка) → подача | 5 |
| Особый | чашка → лист → вода 80° (заварка) → добавка → подача | 9 |

Цены не равны числу шагов: при 3 / 4 / 5 два простых заказа всегда
выгоднее одного сложного, и выбора нет. 2 / 5 / 9 — отправная точка.

Все крутилки — в блоке `TUNING` в начале `kitchen_core.gd`: скорость ходьбы,
время заварки, цены, темп гостей, терпение, доля сложных заказов.

## Открытый вопрос по концепту

Концепт: «~5 партий ≈ 10 минут в день» исходил из партии ~2 мин. Реальная
партия ~3,7 мин, поэтому надо выбрать: 5 партий (~420 монет, ~18 мин) или
10 минут (~3 партии, 250 монет). Сейчас выбрано 10 минут.
